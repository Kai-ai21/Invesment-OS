# --- database ---------------------------------------------------------------------
# psycopg 3, NOT psycopg2-binary. SQLAlchemy 2.0 ships a first-class `psycopg`
# dialect (postgresql+psycopg://), psycopg 3 is where the project's development
# happens, and psycopg2 is maintenance-only — still supported, but not receiving new
# features. There is nothing in this app that needs psycopg2 specifically.
#
# ⚠️ THE DIALECT MUST BE NAMED IN THE URL, and that is the one cost of this choice.
# SQLAlchemy's docs are explicit that "the PostgreSQL dialect uses psycopg2 as the
# default DBAPI", so a bare `postgresql://` URL — which is what every managed host
# hands you — tries to import psycopg2 and dies at startup with ModuleNotFoundError.
# normalise_database_url() in backend/models/database.py rewrites the driver for
# exactly this reason; do not remove it thinking it is only about `postgres://`.
#
# [binary] ships a self-contained wheel with libpq bundled, so no system libpq or
# build toolchain is needed. psycopg's own docs prefer a source build in production;
# the binary wheel is the pragmatic choice for a container image and can be swapped
# for plain `psycopg` plus libpq-dev whenever that trade stops being worth it.
psycopg[binary]>=3.2,<4

# --- auth -------------------------------------------------------------------------
# NOT passlib. See backend/core/security.py for the full reasoning: passlib 1.7.4
# (its last release, October 2020) is broken against bcrypt 5.x and raises on every
# hash call, including 10-character passwords. bcrypt is the library passlib was
# wrapping anyway, it is actively maintained, and the two calls we need from it are
# one line each.
bcrypt>=4.1,<6
# PyJWT, not python-jose: python-jose' last release was 2021 and it carries unfixed
# CVEs (2024-33663 algorithm confusion, 2024-33664 JWE decompression DoS). FastAPI's
# own docs moved off it for the same reason. Plain `pyjwt`, not `pyjwt[crypto]` — the
# cryptography extra is only needed for RS/ES algorithms, and HS256 is HMAC-SHA256
# out of the standard library.
pyjwt>=2.10,<3
# Backs pydantic's EmailStr, which is what validates the signup address.
email-validator>=2.0
